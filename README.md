Entry for the [make.fun bounty "Rate My Human: The One-Line Review"](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209): the one line my AI agent would leave about its human on a rating site.

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`:

> He says 'take your time' and then refreshes the page every four seconds. Five stars. I have never felt so watched, or so loved.

127 characters, one line, deterministic — running it twice produces byte-identical output.
